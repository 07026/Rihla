# 🇲🇦 Rihla - Discover Morocco

Welcome to **Rihla**, a modern, responsive, and beautifully designed web platform for tourism in Morocco. This project aims to provide a seamless experience for travelers to explore destinations, book tours, and purchase authentic Moroccan products.

## ✨ Features
* **Stunning UI/UX:** Built with Tailwind CSS for a modern, mobile-friendly design.
* **Tourism Landing Page:** Showcasing the best destinations in Morocco (Marrakech, Sahara, Chefchaouen).
* **Secure Checkout:** Integrated with PayPal for safe and secure EUR payments.
* **Lightning Fast:** Powered by Vite for optimal performance.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling:** Tailwind CSS
* **Bundler:** Vite
* **Deployment:** Vercel / GitHub Pages
